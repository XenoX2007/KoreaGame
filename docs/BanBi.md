## Summary

Turn-based ring-knockout marbles. 1v1 or 2v2 (team = `id % 2`: even = left/Vietnamese, odd = right/Korean). A dirt ring holds 5 neutral marbles; each player has one shooter marble in their seat color. Players take turns flicking with one button (press = lock aim, hold = pull back, release = flick). Knock rival marbles out to eliminate them and neutral marbles out to score. Round length about 2–3 minutes.

Avoid Squid Game associations: no "odd or even" guessing, no marble pouches/bags, no doll, red suits or masks.

## Phases (state machine in the model)

`DiceRoll → Aiming → Charging → Rolling → (Aiming | Finished)`

Plus `Countdown` before `DiceRoll` handled by `PanelMiniGame` as in other games.

### 1. DiceRoll
- Every seat shows a die cycling 1–6 every `diceFaceSeconds`.
- A press (pressed = true) stops that player's die on the face shown at the press time. Faces come from a seeded RNG so tests are deterministic.
- After `diceAutoStopSeconds` a die still spinning stops on its current face.
- Ties for the highest roll among players who need ordering: only the tied players reroll.
- Turn order: the highest roller first, then teams strictly alternate. Within a team, the higher roller goes first (tie inside a team: reroll those two). In 1v1 this is just highest first, then alternate.
- Inputs from other phases are ignored here; presses during DiceRoll never start a shot.

### 2. Aiming (active player only)
- Inputs from non-active players are ignored for the whole turn.
- Aim angle sweeps sinusoidally ±`aimSweepDegrees` around the base direction at `aimSweepHz`:
  - shooter on its seat edge (or outside the ring) → base = toward ring center
  - shooter inside the ring → base = toward nearest alive rival marble; if none, ring center
- `turnSeconds` timer starts when the turn starts. Timeout with no press → turn skipped (counts toward the turn limit, no bonus).
- Press → lock the aim angle at the press time → `Charging`.

### 3. Charging
- Power = triangle wave 0 → 1 → 0 with a period of `2 * chargeSeconds`, starting at 0 on press. Holding too long loses power.
- Release → launch the shooter at speed `lerp(minShotSpeed, maxShotSpeed, power)` along the locked angle → `Rolling`.
- The turn timer is paused while charging (so a long hold doesn't skip the turn) but charging is capped: if held for `maxHoldSeconds`, it auto-releases at the current power.

### 4. Rolling — physics
All in normalized ring units: ring radius = 1, center = (0, 0).
- Fixed substep `physicsStep` (1/240 s). The model's `Advance(double time)` runs as many substeps as fit since the last call (accumulator), so results don't depend on frame rate.
- Each marble: position, velocity, radius (`marbleRadius` for all, ~0.06).
- Rolling friction: constant deceleration `friction` (units/s²); a speed below `stopSpeed` snaps to 0.
- Marble–marble: equal-mass circle collision, positional separation, restitution `restitution` (0.9).
- No walls: marbles can roll anywhere; "out" is checked when everything stops.
- The step ends when every marble's speed is 0, or after `maxRollSeconds` (then force-stop all).

### Out rule (evaluated once when rolling stops)
A marble is out when `|position| > 1` (its center crosses the ring line).

| Marble out | Effect |
|---|---|
| Neutral | Removed. Shooter's team +`neutralPoints` (1). Grants a bonus shot. |
| Rival shooter | That player is eliminated for the rest of the round; marble removed. Shooter's team +`rivalPoints` (2). Grants a bonus shot. |
| Own or teammate's shooter | Not eliminated. Marble is placed back on its seat-edge start spot for its next shot. No points. |

Out marbles fly past the line visually but are removed from the simulation when rolling stops.
"Shooter" for scoring = the active player who took the shot (chain hits count for them).

### Bonus shots and turn end
- A shot that earned any bonus → same player goes again (`Aiming`), up to `maxBonusShots` (2) chained bonus shots per turn. Bonus shots don't count toward the turn limit.
- Otherwise the turn passes to the next alive player in turn order (eliminated players are skipped).
- Start spots: each seat has a fixed spot on the ring edge nearest its seat (angle from `SeatLayout` seat direction). If another marble overlaps that spot when placing, nudge outward along the radius until clear.

### 5. Finished
- **Instant win:** after a shot resolves, if every rival of one team is eliminated → that team wins.
- **Turn limit:** after every alive player has taken `turnsPerPlayer` (6) regular turns → higher team points wins.
- **Tie on points:** the team owning the alive shooter marble closest to the center wins. Still tied (e.g. none alive or equal distance) → draw, `HasWinner = false`.
- `GetRanking()`: teammates share rank. Winning team rank 1, losing team rank 2; draw → everyone rank 1. Use `RanksFromScores` with team score (e.g. win = 1, lose = 0) mapped to each player id.

## Model API (sketch)

```csharp
public sealed class BanBiModel
{
    public BanBiModel(BanBiSettings settings, int playerCount, int seed, IReadOnlyList<Vector2> startSpots);
    public BanBiPhase Phase { get; }
    public int ActivePlayer { get; }             // -1 outside a turn
    public IReadOnlyList<int> TurnOrder { get; }
    public IReadOnlyList<MarbleState> Marbles { get; }   // owner id or -1 for neutral, pos, vel, alive
    public int[] TeamPoints { get; }             // [0] = left, [1] = right
    public bool IsEliminated(int player);
    public int DiceFace(int player, double time);
    public float AimAngle(double time);          // radians, valid in Aiming/Charging
    public float Power(double time);             // 0..1, valid in Charging
    public double TurnTimeLeft(double time);
    public int WinnerTeam { get; }               // -1 none/draw
    public void Start(double time);              // enters DiceRoll
    public void Press(int player, bool pressed, double time);
    public void Advance(double time);            // phases, timers, physics substeps
    public event Action<BanBiEvent> Event;       // DiceStopped, TurnStarted, Shot, Hit(a,b,impulse), MarbleOut(id, by), Eliminated, BonusShot, Finished
}
```

Only `System` / `UnityEngine.Vector2`/`Mathf` maths; no MonoBehaviour, no `Time`. All times are explicit `double` arguments, as in `KeoCoModel`.

## View (`BanBiGame : PanelMiniGame`)

- Implements `Bind(root)`, `FunFacts`, `Setup(playerCount)`, `OnPlayerInput`, `GetRanking()`; calls `EndRound(title)`.
- HUD must contain `seatLayer`, `timer`, `centerMessage`, `togglePlayers`, and instances of `ResultsOverlay.uxml` and `PauseOverlay.uxml` (see CLAUDE.md).
- Uses `Now` (PausableClock) for every model call; never `Time.time`.
- The ring sits on the ground band (`FarGround`..`NearGround`): map ring units to an ellipse (horizontal radius × depth-squashed vertical radius) and scale marbles with `DepthScale`. Ring ellipse constants must match `.ring` in `BanBiHud.uss` (comment both sides, as with `TrackHalfWidth`/`.win-line`).
- Players stand behind their seat's start spot as `CharacterView` (left team Vietnamese, right team Korean), facing the ring.
- Active turn: the active player's hand sprite appears at their marble (rotated to the aim angle), aim arrow + power arc drawn in UI Toolkit; other seats get a `.is-waiting` dim class. Pull-back pose while charging, flick pose for 0.15 s after release.
- Timer pill: shows the turn countdown during Aiming; between turns shows "Lượt x/6".
- Score: two team chips (VN / KR) with points; eliminated players' seat discs greyed with a small ✕.
- Dice: a die element on each seat during DiceRoll; then the turn order as small numbers 1..4 on seats.
- Marbles drawn as pooled UI elements with a separate ground shadow. A marble going out flies past the line, fades, and plays the out sound.
- Center messages: "Đổ xúc xắc!", "Lượt của P{n}", "Thêm lượt!", "Loại!".
- Online: not in scope. Turn-based design should make it easy later (host runs the model; only the active phone's presses matter).

## Tests (`Assets/Tests/PlayMode/BanBiModelTests.cs`)

Model-only, explicit times, fixed seed:
- Dice: press stops on the shown face; auto-stop after `diceAutoStopSeconds`; ties among highest reroll only the tied players; 2v2 order strictly alternates teams.
- Presses from non-active players are ignored during a turn; presses during DiceRoll never shoot.
- Aim sweep stays within ±`aimSweepDegrees` of base; base points at the nearest rival when inside the ring.
- Power is a triangle wave: 0 at press, 1 at `chargeSeconds`, 0 at `2 * chargeSeconds`; auto-release at `maxHoldSeconds`.
- Turn timeout with no press skips the turn and counts it.
- Physics: head-on equal-mass collision with restitution 1 swaps velocities; total momentum conserved in a collision; a marble with speed v stops after distance v²/(2·friction) (± one step).
- Frame-rate independence: the same shot advanced at 30 fps and 144 fps ends with identical positions (within 1e-4).
- Neutral out → +1 and bonus shot; rival out → eliminated, +2, bonus; own/teammate out → back to start spot, not eliminated, no points.
- Bonus shots cap at `maxBonusShots` and don't count toward `turnsPerPlayer`.
- Eliminated players are skipped in turn order.
- Instant win when all rivals are eliminated; turn-limit win by points; tie broken by closest-to-center; full tie → no winner.
- `GetRanking`: teammates share rank.
